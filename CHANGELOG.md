# Changelog

All notable changes to BenchLog are documented here.

## 0.1.0 - 2026-09-03

- Record commands, timestamps, exit states, selected environment variables, and Git provenance.
- Snapshot JSON configurations, flatten numeric metrics, and capture hashed artifacts.
- Preserve stdout and stderr while optionally echoing them live.
- Compare runs in table, JSON, or CSV form.
- Verify captured files and recover abandoned running manifests.
- Provide a typed Python API, deterministic demo, tests, packaging checks, and cross-platform CI.
